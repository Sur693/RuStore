## О проекте

RuStore — полнофункциональный магазин приложений с собственным бэкендом, развёрнутым в облаке. Поддерживает просмотр каталога, поиск, фильтрацию по категориям, фоновое скачивание и установку APK прямо из приложения.

---

## Экраны

| Экран | Описание |
|---|---|
| Онбординг | Показывается только при первом запуске. Логотип, приветствие, кнопка входа |
| Витрина | Список приложений с иконками, рейтингом и категориями. Фильтрация через чипы |
| Категории | Все категории с количеством приложений. Клик открывает отфильтрованную витрину |
| Поиск | Мгновенный поиск по названию. При пустом запросе — популярные приложения |
| Карточка приложения | Иконка, описание, разработчик, возрастной рейтинг, скриншоты, кнопка установки |
| Просмотр скриншотов | Полноэкранный режим с горизонтальной прокруткой, открывается с выбранного |

## Технологии

**Приложение**
- Kotlin 2.0 + Jetpack Compose + Material3
- MVVM архитектура — ViewModel + StateFlow
- Navigation Compose — навигация между экранами
- Retrofit + OkHttp — сетевые запросы
- Coil — загрузка изображений
- Foreground Service — фоновая загрузка APK
- PackageInstaller API — установка и удаление приложений

**Сервер**
- Ktor 3.0.3 на Netty, задеплоен на Railway
- REST API + SSE для уведомлений о статусе загрузки
- Статические ресурсы: иконки, скриншоты, APK-файлы

## Архитектура взаимодействия

```
Android App  ──── GET /apps ──────────────────────►  Ktor Server (Railway)
             ◄─── JSON список приложений ────────────

             ──── POST /downloads ─────────────────►
             ◄─── { taskId } ─────────────────────────

             ──── GET /downloads/{taskId}/events ────►
             ◄─── SSE: прогресс 0% → 50% → 100% ─────

             ──── GET /downloads/{taskId}/result ────►
             ◄─── { apkUrl } ─────────────────────────

             ──── PackageInstaller (системный) ───────►  Установка APK
```

## Каталог приложений

20 приложений в 5 категориях:

- **Финансы** — СберБанк, Т-Банк, ВТБ, Альфа-Банк
- **Инструменты** — Яндекс Диск, CapCut, Яндекс Переводчик, Сканер документов
- **Игры** — Блок бласт, Дурак Онлайн, Слова, Magic Piano Tiles 9
- **Государственные** — Госуслуги, Мой налог, Кладбища Новосибирска, МЧС России
- **Транспорт** — Яндекс Go, 2ГИС, РЖД Пассажирам, Метро Москвы

## Быстрый старт

Подробная инструкция — в файле [SETUP.md](SETUP.md).

```bash
# Клонировать репозиторий
git clone https://github.com/Sur693/RuStore.git

# Открыть папку RuStore/ в Android Studio и нажать Run
```

Сервер уже развёрнут в облаке — локально запускать ничего не нужно.
